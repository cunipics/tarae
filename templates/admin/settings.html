지능형 검출 설정

크롤링 시작 전 URL 버퍼 생성 단계에 사용할 소스와 제어 옵션을 설정합니다. 부하가 많은 항목은 상황에 맞게 OFF 할 수 있습니다.

알려진 검색내용 활용 (DuckDuckGo 색인 Dorking)

검색엔진 색인에서 오염 키워드(환경변수 SEARCH_DORK_KEYWORDS)로 노출된 URL을 역조회하여 노출된 색인 게시판부터 우선 크롤링. (외부 무료, 기본 ON)

Common Crawl 역조회

과거 크롤에서 발견된 URL 역조회. 링크가 끊어진 스팸 페이지 발굴에 유용. (외부 API, 무료)

urlscan.io 히스토리 역조회

보안 연구자 스캔 기록에서 URL 발굴. (외부 API, 무료)

알려진 취약점 공략 (CMS 딕셔너리)

CMS 식별 후 그누보드5, WordPress, 전자정부프레임워크(CVE), 나모CrossEditor(KISA) 등 취약 경로 자동 공략.

RSS/Atom 피드 URL 수집

사이트의 RSS/Atom 피드에서 게시물 URL을 추가로 수확.

URL 무한증식 방지 정규화

동일 구조 중복 매개변수나 루프 경로를 정규화하여 제거.
하위 디렉터리 경로 계층 한도. 초과 시 버퍼에서 제외.
